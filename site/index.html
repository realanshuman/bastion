For developers

Fits how you already work

A command line, an MCP server for your AI agent, a GitHub Action and git hooks. Use one, or all of them.

# Is it safe to install and run here?
$ bastion check && npm install
✓ safe to run on main

# What needs me, with proof and the fix
$ bastion todos
● dormant  Delete the old branch release/1.4 — main is clean
  proof: postcss.config.mjs: Line 8 looks like “};”, but 2,000 blank
         characters push hidden code off-screen, from column 2,003
  one step: bastion fix 3k9x2ab --yes
# Claude Code: your agent checks a repo before it runs npm there
$ claude mcp add --scope user bastion -- ~/.security-guard/bin/bastion mcp

# Hard-guard: block install, dev, build and test in an unsafe repo
$ bastion hooks install claude   # or cursor

# Cursor, Claude Desktop, Windsurf and Codex: one command each
$ bastion connect cursor --write

# Agents can turn protection on, never off.
# .github/workflows/bastion.yml: fails a pull request that carries a payload
name: Bastion
on: [pull_request]
jobs:
  bastion:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: realanshuman/bastion@v4
# Refuse to push a commit that carries the payload, in every repo
$ bastion enable git-guard

# Repos that use husky get the check in .husky/pre-push
$ bastion enable git-guard --husky ~/code/storefront

# npm, node, pnpm, yarn and bun refuse to run in an infected project
$ bastion enable exec-guard

Built to be trusted

Careful by design

Proof, not alarms

Every finding names the line and the column. If Bastion can't show you the code, it doesn't raise the alarm.

Nothing destructive

Leftovers are quarantined, never deleted. Every file Bastion cleans has an undo.

Agents can't weaken it

AI agents can turn protection on, never off. Lowering it is yours to do, and it's logged.

Runs on your Mac

No account and no cloud. The optional online check sends package names and versions, never your code.

Fast

A full scan of 15 repositories takes about 6 seconds. Checking one project takes under a second.

Open source

MIT licensed. Every rule Bastion uses to decide is in the repository for you to read.
